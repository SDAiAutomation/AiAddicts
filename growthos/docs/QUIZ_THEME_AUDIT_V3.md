# Quiz visual audit — renderer v3

The requested branches contained eight renderer themes (`studio`, `arcade`, `education`, `sport`, `pop`, `minimal`, `photo`, `logo`). This change adds `vault`, `boss`, and `split` to make eleven. The three new themes have distinct Motion entrances, stage motifs, and reveal openings; they use the existing libass/FFmpeg renderer and no new provider call. Classic keeps its established card layout with the new palettes.

The renderer chooses foreground colours for correct-answer cards and accent surfaces using relative luminance. A prior Classic green reveal used white lettering with insufficient contrast; the new choice is checked at a minimum of 4.5:1 for every theme. The portrait card width is now bounded to 10–88% of the frame, and the Classic progress badge starts at 12% from the top. These are layout choices for mobile platform overlays, not a guarantee for every future platform UI.

`python scripts/audit_quiz_themes.py --resolution 720x1280` and `--resolution 1280x720` render a fixed four-choice question and reveal through the real caption overlay for Classic and Motion. The contact sheets are written under `output/quiz-theme-audit/<resolution>/contact-sheet.jpg`; each sheet covers all eleven themes in both presentations. Visual inspection on 19 October 2026 found no clipped question, choice, or reveal text in that reference script and no premature correct-answer styling. The rendered Vault, Boss, Split and Studio previews were also inspected at full portrait resolution. Tests compare question-phase ASS output across different correct-answer indices for every theme and presentation.

These are **synthetic frames**, with fixed timing, no voice and no paid image generation. They do not establish narration, countdown or sound-effect synchronization. Long multilingual text, supplied illustrations and platform-specific UI overlays still need the production renders and review specified in Phase 3. `quiz-motion:v3` changes the render cache key; old saved scripts without a presentation continue to use Classic.

Rollback: revert the theme identifiers/palettes, selector copy and Motion module together. Existing scripts already using `vault`, `boss`, or `split` must be changed to a retained theme before running against the old engine; no SQL migration is involved. The additional ASS shapes can increase CPU rendering time, which Phase 3 will measure. API usage remains unchanged.
